# Suspects Test Build

This build adds the approved Florida rubber-hose character cast to the League of Losers Suspects section.

## Included
- 20 individual transparent PNG character assets in `assets/portraits/suspects/`
- Active suspects shown first in the approved cast order when using Most Wanted sort
- Landscape sheriff case-file directory cards
- Active / Archived case stamps
- Updated View Case File treatment
- Full wanted-poster hero on each individual suspect page
- Florida-themed aliases and humorous charges
- Existing league data, records, filters, navigation, and owner identity mapping preserved

## Test
Open `index.html`, select League of Losers, and choose **The Suspects**.
