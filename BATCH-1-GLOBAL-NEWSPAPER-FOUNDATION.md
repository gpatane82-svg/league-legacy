# Batch 1 — Global Newspaper Foundation

This real Batch 1 pass is rebased on the completed Home + Standings Batch 2 build, so no page-specific Batch 2 work was discarded.

## Shared shell changes

- Replaced the Florida Man promotional masthead with the official League of Losers archive identity.
- Kept Florida Man as editorial flavor inside page content rather than as the primary brand.
- Standardized the desktop and mobile masthead, selectors, navigation, page heading, and footer.
- Removed global palm silhouettes, decorative stamps, slogan ribbons, and the “Florida Vibes / Gridiron Attitude / A Little Chaos” banner.
- Established shared colors: blue for positive/archive structure, orange for negative/Sacko emphasis, cream for neutral surfaces, green for success, and gold for championships.
- Added consistent focus states and responsive behavior.
- Preserved routes, datasets, league switching, Home work, and Standings work from Batch 2.
