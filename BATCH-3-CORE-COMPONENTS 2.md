# Batch 3 — Florida Man Core Component System

This checkpoint replaces the shared Vandelay component language with a Florida-only component system whenever League of Losers is selected.

## Included

- Rugged field-board panels with black outlines, distressed paper texture, and offset shadows
- Road-sign section headers with orange trim and blue season/status tabs
- Four-style scoring/stat tiles based on the approved concept board
- Scoreboard-style standings and archive tables
- Orange first-place rank markers and danger-row accents
- Florida-specific buttons, links, filters, and department controls
- Matchup-board game ledger and scoring treatment
- Trophy-case championship, Sacko, and performance-award cards
- Mugshot/evidence styling for manager cards and portraits
- Florida-colored bars and smaller data visualizations
- Mobile rules for the heavier components

## Isolation

Every Batch 3 rule is scoped beneath `body.theme-florida-man`. The Art Vandelay presentation remains unchanged.

## Batch boundary

Decorative illustrations, alligator artwork, newspaper clippings, stamps, beach props, keeper-specific artwork, and full footer personality remain scheduled for Batch 4.
