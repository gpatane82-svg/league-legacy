# Batch 6 — Home Page Front Page

This release redesigns the Florida Man / League of Losers home page as a true newspaper front page.

## Added
- Edition banner and breaking-news strip
- Data-driven championship lead story
- Current-season standings snapshot and Sacko watch
- Power, scoring, and playoff-race news briefs
- Permanent archive feature story
- All-time wins board and championship podium
- Large editorial navigation directory
- Responsive mobile and tablet layouts

## Preserved
- Art Vandelay home page and styling
- League identity mapping
- Standings and statistical calculations
- Season selector behavior
- All other routes and Commissioner tools
- Imported data files

The home page content is generated only from the existing certified league data. No weekly story facts or results were invented.
