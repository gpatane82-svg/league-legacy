## Publish from GitHub.com

1. Keep a copy of the current repository ZIP as a rollback backup.
2. Extract this ZIP locally.
3. Upload the extracted files and folders to the root of the `main` branch, replacing files when GitHub asks.
4. Commit with a message such as `Add League Legacy archive centers and search`.
5. Open **Actions** and wait for the Pages deployment to finish.
6. Hard-refresh the published site.

No current portrait or Hall image is intentionally deleted by this update.
