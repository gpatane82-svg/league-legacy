# League Legacy — Dual-Theme Release

A static GitHub Pages archive for two fantasy football leagues sharing one historical data system.

## League selector

- **Art Vandelay** preserves the existing Vandelay Industries corporate presentation.
- **League of Losers** activates the independent Florida Man presentation.

The leagues share routes, season filters, manager identities, calculations, game history, drafts, awards, archive search, and source data. The dropdown controls the active presentation system.

## Run locally

Open `index.html`, or serve this folder with any static web server.

## Deploy

Upload the **contents of this folder** to the repository root used by GitHub Pages, commit the changes, and hard-refresh the published site after deployment.

See `BATCH-5-RELEASE-QA.md` and `QA-REPORT.md` for the final validation summary.
