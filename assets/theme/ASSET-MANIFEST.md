# League of Losers — Florida Sheriff Theme Asset Package

## Production assets
- `florida-archive-background.png` — subtle Florida/coastal linework and palms, used globally.
- `aged-paper-texture.png` — seamless-style parchment grain for newspaper and case-file panels.
- `palm-overlay.svg` — scalable corner/edge palm silhouettes.
- `sheriff-star-watermark.svg` — low-opacity department badge watermark.
- `official-records-stamp.svg` — masthead records stamp.
- `case-closed-stamp.svg` — championship case status stamp.
- `torn-paper-edge.svg` — scalable worn paper edge treatment.

## Webfont stack
Loaded from Google Fonts rather than bundled in the ZIP:
- Bebas Neue — primary large display headlines.
- Oswald — navigation, labels, condensed UI typography.
- Libre Baskerville — newspaper/editorial body copy.
- Special Elite — archive, evidence, and typewriter labels.

System fallbacks are included in CSS so the site remains readable if the webfonts cannot load.
