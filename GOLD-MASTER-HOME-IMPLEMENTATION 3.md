# Gold Master Home Implementation

This build establishes the approved Florida Sheriff newspaper design as executable HTML/CSS inside the existing League of Losers application.

## Scope
- Home/overview page only.
- Existing dynamic league data, navigation, selectors, standings, champion, and Sacko content remain intact.
- Suspects and Manager page wood backgrounds remain locked and unchanged.

## Implemented systems
- Florida archival map background using the existing detailed map/palm asset.
- Rebuilt masthead proportions and navigation hierarchy.
- Single-sheet archival paper treatment for the department banner, lead story, and standings.
- Rebuilt Sheriff's Office banner grid to prevent text/volume/bulletin overlap.
- Newspaper display typography with stable local fallbacks and Google Font enhancement when available.
- Case Closed treatment using the transparent SVG asset.
- Champion and Sacko outcome cards using the approved seals.
- Restrained paper aging and coffee-ring treatment.

## Visual QA
Rendered at 1600 × 900 using Chromium against the live application markup and data. The candidate was iterated from the V10.40 canonical build until the banner no longer overlapped, the headline fit the approved two-line hierarchy, and the paper panels rendered as continuous sheets.
