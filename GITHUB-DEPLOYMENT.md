# GitHub Deployment Checklist

1. Download and unzip the final release.
2. Open the included `league-legacy-main-4` folder.
3. Upload the **contents inside that folder** to the GitHub Pages repository root, replacing the previous site files.
4. Commit the upload.
5. Wait for the GitHub Pages deployment to finish.
6. Open the live site in a private window or hard-refresh to bypass cached CSS and JavaScript.
7. Test both league selections and every navigation route.

Do not upload the outer ZIP itself as the website and do not add an extra nested folder above `index.html` unless the repository is intentionally configured for that subdirectory.
