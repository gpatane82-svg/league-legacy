# Batch 7 — Owner Directory & Profiles

This release redesigns the Florida Man owner directory and individual owner profiles while preserving the existing data model, routes, season selector, internal links, and Art Vandelay presentation.

## Owner Directory

- Editorial public-records masthead and archive totals
- Responsive owner card grid replacing the Florida directory table
- Owner portraits, active/archive status, franchise identity, career or season record, win rate, titles, Sackos, and points
- Direct links from every card to the corresponding owner profile

## Owner Profiles

- Full portrait-led Florida Bureau rap-sheet header
- Career rankings and performance scoreboard
- Season-specific incident report when a year is selected
- Rivalry intelligence, favorite victim, most-played rival, and recorded high score
- Championship and Sacko cabinet
- Combined career milestone timeline
- Expanded season-by-season performance ledger
- Responsive layouts for desktop, tablet, and mobile

## Scope

- Florida Man theme only
- No league facts, imported records, IDs, or archive sources were changed
- Art Vandelay owner pages remain unchanged
